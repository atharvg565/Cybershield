How to interpret: False negatives are scams the model missed; false positives are legitimate items incorrectly flagged. For security systems, both matter. A high overall accuracy alone can hide missed scams, so review recall, precision and the confusion matrix together.
Evaluation results are from the project's recorded offline tests, not live website traffic. The 40-message test is small and team-authored; results may not generalize to real-world messages. URL-model results use a separate held-out URL dataset and must not be compared directly with the message test as if they were the same task.
